# آمار و نتایج انتخابات شورای مشورتی دانشجویان

سایت تک‌صفحه‌ای (HTML + CSS + Vanilla JS، بدون بیلد) برای دانشکده مهندسی مواد و متالورژی، دانشگاه فردوسی مشهد.

## انتشار روی GitHub Pages
1. همه فایل‌ها را در ریشه یک مخزن بگذارید.
2. Settings ← Pages ← Source: `Deploy from a branch` ← شاخه `main` و پوشه `/ (root)`.

## ساختار
```
index.html  style.css  app.js
data/fallback.json   ← داده پشتیبان هنگام خطای شبکه
```

## منبع داده
آدرس CSV در بالای `app.js` (`CONFIG.csvUrl`) است. صفحه هر ۶۰ ثانیه داده را دوباره می‌خواند. گوگل‌شیت خودش خروجی منتشرشده را چند دقیقه کش می‌کند، پس تأخیر کوتاه طبیعی است.

## قالب‌های پشتیبانی‌شده CSV
نام ستون‌ها و کلیدها در بخش `MAP` بالای `app.js` قابل تغییر است (فارسی یا انگلیسی).

**الف) یک جدول با ستون `type`**
```
type,key,value,year,eligible,voted,name,votes
meta,showCandidateVotes,false,,,,,
meta,status,رأی‌گیری در جریان,,,,,
meta,endTime,18:00,,,,,
meta,mainSeats,5,,,,,
meta,reserveSeats,2,,,,,
entry,,,1402,80,41,,
candidate,,,,,,علی رضایی,37
```

**ب) چند جدول جدا با سطر خالی بین آن‌ها**
```
key,value
showCandidateVotes,true
status,پایان یافته

year,eligible,voted
1402,80,41

name,votes
علی رضایی,37
```

**پ) فقط کلید-مقدار بدون سرستون** (برای بخش متا)، یا **ت) جدول تک‌سطری متا** با کلیدها به‌عنوان سرستون.

## کلیدهای متا
| کلید | کاربرد |
|---|---|
| `showCandidateVotes` | `true/1/yes` نمایش آرا، `false/0/no` مخفی |
| `status` | متن وضعیت (باز، در جریان، پایان‌یافته و ...) |
| `lastUpdate` / `endTime` | آخرین به‌روزرسانی و ساعت پایان (متن آزاد) |
| `mainSeats` / `reserveSeats` | تعداد اعضای اصلی و علی‌البدل (پیش‌فرض ۵ و ۲) |
| `totalEligible` / `totalVoted` | اختیاری؛ در غیاب آن‌ها از جمع سال‌های ورودی محاسبه می‌شود |

## رفتار نمایش آرا
- **خاموش:** فقط نام کاندیداها (به ترتیب الفبا) نمایش داده می‌شود. تعداد رأی و رتبه اصلاً در صفحه ساخته نمی‌شود.
- **روشن:** مرتب‌سازی نزولی، تعداد و درصد رأی (نسبت به کل شرکت‌کنندگان)، نوار پیشرفت و برچسب «منتخب اصلی» و «علی‌البدل».

> توجه: چون سایت استاتیک است، ستون آرا در خود CSV منتشرشده برای هر کسی که لینک را داشته باشد قابل دیدن است. اگر پنهان بودن واقعی لازم است، ستون آرا را تا زمان اعلام نتایج در شیت خالی بگذارید.
